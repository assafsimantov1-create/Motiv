# MOTIV — אתר מכירה לתומך כתף

אתר סטטי מלא, מוכן להעלאה. אין תהליך build, אין תלויות, אין שרת.
פותחים את `index.html` בדפדפן וזה עובד.

```
motiv-site/
├── index.html          ← מבנה הדף
├── styles.css          ← כל העיצוב
├── script.js           ← STORE_CONFIG + כל הלוגיקה
├── assets/             ← התמונות
└── README.md
```

---

## 1. העלאה לאוויר

**Vercel:** https://vercel.com/new → גררו את התיקייה → Deploy.
**Netlify:** https://app.netlify.com/drop → גררו את התיקייה.
**כל אחסון אחר:** העלו את תוכן התיקייה לשורש הדומיין.

אחרי ההעלאה עדכנו ב-`index.html` שתי שורות:

```html
<link rel="canonical" href="https://YOUR-DOMAIN.com/">
<!-- <meta property="og:url" content="https://YOUR-DOMAIN.com/"> -->
```

## 2. STORE_CONFIG — כל מה שעורכים נמצא בראש `script.js`

| שדה | ברירת מחדל | למה זה משמש |
|---|---|---|
| `brandName` | `"MOTIV"` | שם המותג |
| `singlePrice` | `34.99` | מחיר יחידה אחת |
| `doublePrice` | `49.99` | **לא בשימוש** — אופציית 2 היחידות הוסרה מהדף |
| `discountBadge` | `"מחיר השקה מיוחד"` | התג הצבעוני ליד המחיר. `null` מסתיר אותו |
| `compareAtSingle` | `null` | מחיר מחוק ליחידה. `null` = לא מוצג |
| `compareAtDouble` | `null` | מחיר מחוק לשתי יחידות. `null` = לא מוצג |
| `currency` | `"$"` | הסמל שמוצג בדף |
| `currencyCode` | `"USD"` | קוד המטבע שנשלח לפיקסל ולאנליטיקס |
| `checkoutUrl` | עמוד המוצר ב-Fourthwall | כתובת התשלום שאליה נשלח הלקוח |
| `shippingText` | `null` | טקסט משלוחים אמיתי שלכם |
| `returnPolicyText` | `null` | מדיניות החזרות מלאה |
| `returnPolicyShort` | `null` | גרסה קצרה לשורת האמון |
| `announceText` | `null` | סרגל הודעה עליון |
| `supportEmail` | `null` | מייל תמיכה |
| `whatsappNumber` | `null` | מספר וואטסאפ בפורמט בינלאומי, למשל `972500000000` |
| `metaPixelId` | `null` | מזהה פיקסל מטא |
| `googleAnalyticsId` | `null` | מזהה GA4, למשל `G-XXXXXXX` |
| `reviews` | `[]` | ביקורות אמיתיות בלבד |

> **חשוב:** כל שדה שערכו `null` — האלמנט שלו **מוסתר לגמרי** מהאתר.
> זה מכוון: כך לא מוצגת ללקוח שום הבטחה על משלוח, החזרה או אחריות שלא סיפקתם בעצמכם.
> ברגע שתמלאו טקסט, האלמנט יופיע אוטומטית.

### תצוגת המחיר
המחיר מוצג כ-**$34.99** גדול עם תג **"מחיר השקה מיוחד"** לידו, בלי מחיר מחוק ובלי אחוזי הנחה.
זו מסגרת בטוחה: היא מבטיחה שהמחיר יעלה בעתיד, ולא טוענת שנגבה בעבר מחיר גבוה יותר.

אם בהמשך תעלו את המחיר ותרצו להציג מבצע אמיתי, מלאו את `compareAtSingle`
ואת `compareAtDouble` במחיר שנגבה בפועל, ושנו את `discountBadge` בהתאם —
המחיר המחוק יופיע אוטומטית בבלוק המחיר, בשני כרטיסי ההצעה ובסרגל המובייל.

> **לפני שמציגים מחיר מחוק:** לפי חוק הגנת הצרכן, מחיר "לפני" צריך להיות מחיר
> שנגבה בפועל בתקופה שקדמה למבצע. גם מטא בודקת את זה במודעות מסחר.

**בדף יש כרגע אפשרות רכישה אחת בלבד** — יחידה אחת ב-$34.99.
בורר הכמות הוסר משני המקומות, ובכרטיס ההזמנה מופיעה במקומו שורת מחיר.

הלוגיקה של שתי היחידות עדיין קיימת ב-`script.js` (`doublePrice`, `SelectOffer`,
חישוב המחיר ליחידה והחיסכון) — היא פשוט לא מקבלת אלמנטים בדף ולכן לא רצה.
כדי להחזיר את האפשרות צריך להוסיף בחזרה ל-`index.html` את בלוק
`<div class="offers">` עם שני ה-`<label class="offer">`. העיצוב שלהם עדיין
נמצא ב-`styles.css` תחת `/* offers */`, כך שזו הוספת HTML בלבד.

> **החלפת מטבע:** משנים את `currency` (הסמל בדף) ואת `currencyCode` (מה שנשלח לפיקסל).
> שניהם חייבים להתאים זה לזה, ולמטבע שגובה מערכת הסליקה בפועל.

### צ'ק-אאוט
```js
checkoutUrl: "https://motiv-shop.fourthwall.com/products/new-product",
```

שני כפתורי **"הזמינו עכשיו"** — זה שבהירו וזה שבאזור ההזמנה — הם **קישורים** (`<a>`)
שנפתחים בלשונית חדשה, עם הבחירה של הלקוח מצורפת לכתובת:

```
https://motiv-shop.fourthwall.com/products/new-product?size=M&qty=2
```

שאר הכפתורים בדף (בתפריט העליון, במקטעי התוכן ובסרגל המובייל) גוללים בכוונה
לאזור ההזמנה ולא ישירות לתשלום — כדי שהלקוח יבחר מידה לפני שהוא עוזב את הדף.

ה-`href` מתעדכן אוטומטית בכל בחירת מידה, כך שהקישור תמיד מצביע ליעד הנכון —
וגם אפשר ללחוץ עליו עם Cmd/Ctrl או לפתוח בלשונית חדשה ידנית.

אם לא נבחרה מידה — הקישור **נחסם** בקוד, גולל לבורר המידות ומדגיש אותו
עם ההודעה "רגע — צריך לבחור מידה לפני שממשיכים".
זה מונע הזמנות בלי מידה, שהן הסיבה מספר אחת להחזרות בקטגוריה הזאת.

**לפתיחה באותה לשונית** במקום בלשונית חדשה: הסירו `target="_blank" rel="noopener"`
משני הקישורים ב-`index.html`.

> **למה קישור ולא כפתור?** כפתור שמנווט דרך `window.location` נחסם בשקט
> בתוך תצוגות מוטמעות (iframe עם sandbox) — כמו בתצוגה המקדימה. קישור `<a>`
> עם `target="_blank"` עובד בכל סביבה.

> **שני דברים לוודא ב-Fourthwall:**
> 1. שהמחיר שם הוא $34.99 בדיוק, ובדולרים — אחרת הלקוח יראה סכום אחר במעבר.
> 2. שהמוצר שם נמכר ביחידה אחת. אם מוגדרת שם אפשרות של 2 יחידות — היא לא תואמת לדף.\n> 3. שקיימות שם ארבע וריאציות מידה (S/M/L/XL). Fourthwall מנהל את בחירת המידה
>    בעמוד שלו, כך שהלקוח יבחר פעמיים. אם זה מפריע — אפשר להסיר את בורר המידות
>    מהאתר, אבל אז מאבדים את השאלה "איזו מידה?" מהשלב שבו הלקוח עדיין קורא את טבלת המידות.

## 3. פיקסל ומדידה

יש שתי דרכים, בחרו אחת:

1. **דרך ה-config** — מלאו `metaPixelId` ו/או `googleAnalyticsId` ב-`script.js`. הסקריפט נטען לבד.
2. **דרך ה-HTML** — ב-`<head>` של `index.html` יש שני בלוקים בהערה. הסירו את סימוני ההערה והחליפו את המזהים.

האירועים שנשלחים אוטומטית:

| אירוע | מתי |
|---|---|
| `PageView` | טעינת עמוד |
| `ViewContent` | אחרי טעינת הדף (מוצר נצפה) |
| `SelectSize` | בחירת מידה |
| `SelectOffer` | מעבר בין כמויות — לא פעיל כרגע (יש אפשרות רכישה אחת) |
| `InitiateCheckout` | לחיצה על "הזמינו עכשיו" עם מידה שנבחרה, כולל ערך ומטבע (`currencyCode`) |

**אין אירוע `Purchase`** — הוא צריך לרוץ רק אחרי תשלום שאושר בפועל, בעמוד התודה של מערכת הסליקה.

## 4. ביקורות

מקטע הביקורות **מוסתר לחלוטין** כברירת מחדל. אין באתר ולו ביקורת אחת מומצאת,
אין דירוג כוכבים, אין "X אנשים קנו היום", אין טיימר ספירה לאחור ואין התראות מלאי.

כשיהיו לכם ביקורות אמיתיות שקיבלתם אישור לפרסם:

```js
reviews: [
  { name: "שם הלקוח", text: "מה שהוא כתב", stars: 5 }
]
```

המקטע ייחשף אוטומטית ברגע שיהיה בו לפחות פריט אחד.

## 6. נגישות וביצועים

- HTML סמנטי, `lang="he"`, `dir="rtl"`
- כל התמונות עם `alt` בעברית ועם `width`/`height` (מונע קפיצות פריסה)
- כל התמונות מתחת לקיפול נטענות ב-`loading="lazy"`
- בוררי המידה והכמות הם רדיו אמיתיים — עובדים במקלדת ובקורא מסך
- `:focus-visible` מוגדר לכל אלמנט אינטראקטיבי
- `prefers-reduced-motion` מכובד
- אפס ספריות חיצוניות. הנכס הכבד היחיד הוא הפונט Heebo מ-Google Fonts

## 7. מה עוד צריך להשלים לפני קמפיין

1. **`checkoutUrl`** — בלעדיו אי אפשר לקנות.
2. **מדיניות משלוחים והחזרות** — `shippingText`, `returnPolicyText`, `returnPolicyShort`.
   בלעדיהם המקטעים מוסתרים, וזה פוגע באמון בעמוד מוצר.
3. **דומיין** — ב-`canonical` וב-`og:url`.
4. **פיקסל מטא** — לפני שקל ראשון של תקציב מודעות.
5. **מייל תמיכה או וואטסאפ** — לפחות אחד מהם.
6. **ביקורות אמיתיות** — אחרי המכירות הראשונות.
7. **תמונות נוספות** — ראו `IMAGE-ASSET-PLAN.md`.
